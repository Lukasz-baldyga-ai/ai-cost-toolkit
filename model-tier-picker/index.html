How this works

Every provider, OpenAI, Google, Anthropic, ships roughly the same three tiers: a small, fast, cheap model, a balanced mid-tier model, and a frontier model for the hardest reasoning problems. The price gap between the cheapest and most expensive tier is often 10x or more for the exact same task, so the real question is never "which model is best," it's "what tier does this specific task actually need."

This tool answers that with plain if/else rules based on your answers above, not a model call. No data leaves your browser. Nothing is stored or sent anywhere.
